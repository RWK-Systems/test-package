# Microsoft Store submission

TestPackage uses the Microsoft Store's unpackaged Win32 (EXE) submission path. This preserves the existing NSIS installation behavior and is appropriate because release executables and the installer are signed with Azure Trusted Signing.

## One-time Partner Center setup

1. Sign in to Partner Center with an active Windows developer account.
2. Reserve the product name **TestPackage Generator**.
3. Create a new **EXE or MSI** app submission.
4. Use the values in `submission.json` and the copy in `listing-en-US.md`.
5. Upload the required Store artwork and screenshots.
6. Provide the versioned installer URL generated by the Store preparation workflow.
7. Submit for certification after reviewing the package and listing details.

Do not use the moving `latest` release URL. Partner Center requires a versioned HTTPS URL whose binary remains unchanged.

## Prepare a release for submission

Run **Actions → Prepare Microsoft Store submission → Run workflow**, enter a stable release version such as `2.5.1`, and download the `microsoft-store-v2.5.1` artifact. The workflow:

- verifies the matching GitHub release is not a prerelease;
- downloads `TestPackageSetup.exe` from its immutable, versioned release URL;
- verifies Authenticode signing;
- confirms silent installation and uninstall in a Windows runner;
- records the URL, SHA-256 digest, size, signature status, and tested commands; and
- packages the installer, listing copy, icon, and submission metadata for Partner Center.

Each Store update must use a new, increasing app version and a new versioned installer URL.

## Required manual assets

The repository contains the 1024 x 1024 app icon. Before the first submission, capture current screenshots of the Configurator at Store-recommended sizes and provide any additional artwork requested by Partner Center. Screenshots should show the actual current application UI and must not be fabricated from the listing copy.

## Secrets and credentials

The release workflow already uses Azure Trusted Signing. Partner Center credentials are intentionally not stored in this repository. The first listing can be completed manually; API automation can be added after the product exists and its Partner Center identifiers are known.
